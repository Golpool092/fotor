Какой фоторедактор выбрать?

Для смартфона: Если вам нужен профессиональный результат - Lightroom, для быстрой обработки - Snapseed, для творческих эффектов - VSCO.

Для компьютера: Photoshop - для максимальных возможностей, Affinity Photo - как альтернатива с единоразовой оплатой, GIMP - бесплатное решение.
